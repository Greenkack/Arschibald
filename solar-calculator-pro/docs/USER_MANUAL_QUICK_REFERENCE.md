# Solar Calculator Pro - Quick Reference Guide

**Version 1.0** | **Quick Start Guide for New Users**

---

## 🚀 Quick Start (5 Minutes)

### 1. First Launch
1. Open Solar Calculator Pro
2. Complete setup wizard
3. Create admin account
4. Skip data migration (if new user)

### 2. Create Your First Solar Project
1. Click **Solar Calculator** in sidebar
2. Click **New Calculation**
3. Enter:
   - Location address
   - Roof area (m²)
   - Annual consumption (kWh)
4. Select module type
5. Click **Calculate**
6. View results
7. Click **Save Project**

### 3. Generate PDF Report
1. Open saved project
2. Click **Generate PDF**
3. Select template
4. Click **Generate**
5. Download or email

---

## 📋 Common Tasks

### Create New Project
`Ctrl/Cmd + N` or Click **+ New Project**

### Upload Price Matrix
1. **Price Matrix** → **Upload**
2. Select Excel file
3. Confirm upload
4. Click **Activate**

### Add Customer
1. **CRM** → **New Customer**
2. Enter name and contact info
3. Click **Save**

### View 3D Model
1. Open solar project
2. Click **3D View**
3. Use mouse to rotate/zoom

### Export Results
1. Open project
2. Click **Export** → Select format
3. Choose location → Save

## 🔧 Quick Troubleshooting

### App Won't Start
- Wait 30 seconds for backend
- Restart application
- Check firewall settings

### Calculation Error
- Upload price matrix
- Activate matrix
- Check input values

### PDF Won't Generate
- Check disk space
- Verify all data present
- Try different template

### 3D View Not Loading
- Update graphics drivers
- Enable hardware acceleration
- Reduce quality settings
