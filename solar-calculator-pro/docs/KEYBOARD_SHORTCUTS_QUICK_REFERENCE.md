# Keyboard Shortcuts Quick Reference

## Essential Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+?` | **Show All Shortcuts** |
| `Ctrl+K` | Command Palette |
| `Ctrl+/` | Search |
| `Ctrl+S` | Save |
| `Ctrl+Q` | Quit |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+H` | Home |
| `Ctrl+Shift+S` | Solar Calculator |
| `Ctrl+Shift+H` | Heat Pump |
| `Ctrl+Shift+P` | Price Matrix |
| `Ctrl+Shift+D` | PDF Generation |
| `Ctrl+Shift+C` | CRM |
| `Ctrl+,` | Settings |

## View

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | Toggle Sidebar |
| `Ctrl++` | Zoom In |
| `Ctrl+-` | Zoom Out |
| `Ctrl+0` | Reset Zoom |
| `F11` | Fullscreen |

## Context Actions

### Solar Calculator
- `Ctrl+N` - New Project
- `Ctrl+Enter` - Calculate
- `Ctrl+3` - Toggle 3D View

### PDF Generation
- `Ctrl+G` - Generate PDF
- `Ctrl+P` - Preview
- `Ctrl+D` - Download

### CRM
- `Ctrl+N` - New Customer
- `Ctrl+O` - New Offer
- `Ctrl+T` - New Task

## Tips

- Press `Ctrl+Shift+?` anytime to see all shortcuts
- Shortcuts can be customized in Settings
- Context shortcuts only work on specific pages
- Use `Ctrl+K` for quick command access
