## Complete Solar Project Workflow

**Goal**: From initial customer inquiry to completed installation

### Phase 1: Customer Inquiry (Day 1)

1. **Create Customer Record**
   - CRM → New Customer
   - Enter contact information
   - Add source (how they found you)
   - Assign to sales rep
   - Add initial notes

2. **Schedule Site Visit**
   - CRM → Customer → Tasks
   - Create "Site Visit" task
   - Set date and time
   - Add location
   - Assign team member

3. **Send Initial Information**
   - CRM → Customer → Communications
   - Select email template "Initial Inquiry Response"
   - Attach company brochure
   - Send email

### Phase 2: Site Assessment (Day 3-5)

1. **Conduct Site Visit**
   - Measure roof dimensions
   - Note roof type and angle
   - Check orientation
   - Identify obstacles/shading
   - Take photos
   - Review electricity bills

2. **Upload Site Photos**
   - Projects → New Project
   - Enter project name
   - Link to customer
   - Documents tab → Upload photos
   - Add notes about site conditions

3. **Log Site Visit**
   - CRM → Customer → Communications
   - Add meeting note
   - Record discussion points
   - Note customer preferences
   - Set follow-up date

### Phase 3: System Design (Day 6-7)

1. **Create Solar Calculation**
   - Solar Calculator → New Calculation
   - Enter site data:
     - Address
     - Roof area (from measurements)
     - Roof type and angle
     - Orientation
   - Enter consumption data (from bills)
   - Select module type (customer preference)
   - Add battery if requested
   - Click Calculate

2. **Review Results**
   - Check system size is appropriate
   - Verify production estimates
   - Review financial analysis
   - Check payback period

3. **Create Variants** (if needed)
   - Save initial calculation
   - Create Variant → Different module type
   - Create Variant → With/without battery
   - Compare scenarios

4. **Select Best Option**
   - Compare variants side-by-side
   - Consider customer budget
   - Mark preferred option
   - Add recommendation notes

### Phase 4: 3D Visualization (Day 7)

1. **Generate 3D Model**
   - Open calculation
   - Click 3D View
   - Review automatic placement
   - Adjust if needed

2. **Create Presentation Materials**
   - Export high-res images (front, side, top views)
   - Create 360° animation
   - Export as GIF for email
   - Save screenshots for PDF

### Phase 5: Offer Creation (Day 8)

1. **Generate PDF Offer**
   - Open project
   - Generate PDF
   - Select "Professional Offer" template
   - Configure:
     - Include 3D visualizations
     - Include all charts
     - Add company branding
     - Set validity period (30 days)
   - Preview PDF
   - Generate

2. **Review and Customize**
   - Check all data is correct
   - Verify pricing
   - Add custom notes if needed
   - Save PDF to project

3. **Create Offer Record**
   - CRM → Customer → Create Offer
   - Link to project
   - Set payment terms
   - Set delivery time
   - Add special conditions
   - Save offer

### Phase 6: Offer Presentation (Day 9-10)

1. **Schedule Presentation Meeting**
   - CRM → Tasks → New Task
   - "Present Offer to Customer"
   - Set date/time
   - Add calendar invite

2. **Send Offer**
   - CRM → Customer → Offers
   - Select offer
   - Click "Send to Customer"
   - Customize email message
   - Attach PDF
   - Send

3. **Track Offer Status**
   - System tracks when customer opens email
   - Status updates automatically
   - Set reminder for follow-up (7 days)

### Phase 7: Follow-up (Day 17)

1. **Check Offer Status**
   - CRM → Offers → Filter by "Sent"
   - Review open offers
   - Check days since sent

2. **Contact Customer**
   - Call customer
   - Log call in CRM
   - Record feedback
   - Answer questions
   - Set next action

3. **Update Offer if Needed**
   - If customer requests changes
   - Open project
   - Modify calculation
   - Generate new PDF
   - Create offer version 2
   - Send updated offer

### Phase 8: Offer Acceptance (Day 20)

1. **Record Acceptance**
   - CRM → Offers → Select offer
   - Change status to "Accepted"
   - Add acceptance date
   - Add signed contract (if received)

2. **Update Project Status**
   - Projects → Select project
   - Change status to "Active"
   - Add notes

3. **Create Installation Tasks**
   - Projects → Tasks tab
   - Create task checklist:
     - Order materials
     - Schedule installation
     - Arrange permits
     - Confirm with customer
   - Assign tasks to team

### Phase 9: Installation (Day 30-35)

1. **Pre-Installation**
   - Verify all materials received
   - Confirm installation date with customer
   - Send reminder email
   - Prepare installation team

2. **During Installation**
   - Update task status as work progresses
   - Take installation photos
   - Upload to project documents
   - Note any issues or changes

3. **Post-Installation**
   - Complete final tasks
   - Upload commissioning documents
   - Take final photos
   - Get customer signature

### Phase 10: Project Completion (Day 36)

1. **Final Documentation**
   - Generate final PDF report
   - Include as-built documentation
   - Include commissioning certificates
   - Include warranty information
   - Send to customer

2. **Update Project Status**
   - Change status to "Completed"
   - Add completion date
   - Archive project

3. **Customer Follow-up**
   - Send satisfaction survey
   - Schedule 3-month check-in
   - Add to maintenance schedule
   - Request review/referral

## Heat Pump Installation Workflow

### Phase 1: Initial Assessment

1. **Create Customer and Project**
   - CRM → New Customer
   - Projects → New Project (Type: Heat Pump)

2. **Gather Building Information**
   - Schedule site visit
   - Measure building dimensions
   - Check insulation quality
   - Review current heating system
   - Collect energy bills

3. **Create Heat Pump Calculation**
   - Heat Pump Calculator → New
   - Enter building data
   - Enter current consumption
   - Select heat pump type
   - Calculate

### Phase 2: System Design

1. **Review Results**
   - Check recommended size
   - Verify COP/SPF values
   - Review cost analysis
   - Check savings estimates

2. **Consider Combined System**
   - If customer has solar interest
   - Combined Systems → New
   - Enter both solar and heat pump data
   - Review synergy benefits

3. **Create Offer**
   - Generate PDF
   - Include technical specs
   - Include cost comparison
   - Send to customer

### Phase 3: Installation and Completion

- Follow similar process as solar workflow
- Additional considerations:
  - Hydraulic system integration
  - Buffer tank installation
  - Control system setup
  - Commissioning and testing

## Customer Onboarding Workflow

**Goal**: Efficiently add new customers to the system

### Quick Onboarding (5 minutes)

1. **Basic Information**
   - CRM → New Customer
   - Name, email, phone
   - Address
   - Customer type
   - Save

2. **First Contact**
   - Add communication note
   - Record how they found you
   - Note their interest (solar/heat pump/both)
   - Set follow-up task

### Complete Onboarding (15 minutes)

1. **Detailed Information**
   - Complete all contact fields
   - Add company information (if commercial)
   - Add secondary contacts
   - Upload any received documents

2. **Qualification**
   - Add tags (hot lead, qualified, etc.)
   - Set lead score
   - Assign to sales rep
   - Add to appropriate pipeline stage

3. **Initial Communication**
   - Send welcome email
   - Attach company information
   - Schedule discovery call
   - Add to email list

## Offer Creation and Tracking

### Creating an Offer

1. **Prepare Calculation**
   - Complete solar/heat pump calculation
   - Review all data
   - Save project

2. **Configure Offer**
   - Set validity period (typically 30 days)
   - Define payment terms:
     - Deposit amount
     - Milestone payments
     - Final payment
   - Set delivery/installation timeframe
   - Add special conditions

3. **Generate PDF**
   - Select appropriate template
   - Include all relevant sections
   - Add 3D visualizations
   - Preview and generate

4. **Create Offer Record**
   - CRM → Customer → New Offer
   - Link to project
   - Upload PDF
   - Set status to "Draft"

5. **Send to Customer**
   - Review offer one final time
   - Click "Send"
   - Customize email
   - Send
   - Status automatically changes to "Sent"

### Tracking Offers

1. **Monitor Dashboard**
   - CRM → Offers Dashboard
   - View all active offers
   - See status of each
   - Check days outstanding

2. **Automated Tracking**
   - System tracks email opens
   - Notifications for customer actions
   - Automatic reminders for follow-up

3. **Follow-up Process**
   - Day 3: Check if opened
   - Day 7: First follow-up call
   - Day 14: Second follow-up
   - Day 21: Final follow-up
   - Day 30: Offer expires

4. **Handling Responses**
   - **Accepted**: Update status, create tasks
   - **Rejected**: Record reason, archive
   - **Needs Changes**: Create new version
   - **No Response**: Continue follow-up

## Price Matrix Update Workflow

### Monthly Price Update

1. **Receive New Prices**
   - Get updated price list from supplier
   - Review changes
   - Note effective date

2. **Prepare Matrix File**
   - Open current matrix in Excel
   - Update prices
   - Verify formulas still work
   - Check for errors
   - Save as new file

3. **Upload to System**
   - Price Matrix → Upload
   - Select new file
   - System validates structure
   - Review validation report
   - Fix any errors
   - Confirm upload

4. **Review and Test**
   - Preview new matrix
   - Create test calculation
   - Verify prices are correct
   - Compare with old matrix

5. **Activate New Matrix**
   - Click "Activate"
   - Old matrix archived automatically
   - New matrix now active
   - All new calculations use new prices

6. **Notify Team**
   - Send email to sales team
   - Highlight major changes
   - Update any affected pending offers

### Adding New Products

1. **Update Matrix Structure**
   - Add new column for new battery model
   - Or add new row for new module count
   - Fill in prices
   - Save and upload

2. **Update Product Database**
   - Products → Add Product
   - Enter specifications
   - Upload datasheet
   - Link to matrix

3. **Test Integration**
   - Create test calculation
   - Select new product
   - Verify price lookup works
   - Check PDF generation

## Data Migration Workflow

### From Streamlit to Solar Calculator Pro

1. **Prepare for Migration**
   - Backup Streamlit data
   - Review data to be migrated
   - Note any custom configurations

2. **Run Migration Tool**
   - Admin → Data Migration
   - Select Streamlit data directory
   - Choose what to migrate:
     - Projects
     - Customers
     - Calculations
     - Price matrices
     - Settings
   - Start migration

3. **Monitor Progress**
   - Progress bar shows status
   - Log shows items being migrated
   - Errors highlighted

4. **Review Results**
   - Migration report generated
   - Shows:
     - Items migrated successfully
     - Items with errors
     - Items skipped
   - Review error details

5. **Verify Data**
   - Spot-check migrated projects
   - Verify calculations are correct
   - Check customer data
   - Test price matrix lookups

6. **Fix Issues**
   - Manually correct any errors
   - Re-run migration for failed items
   - Update any outdated data

7. **Complete Migration**
   - Confirm all data migrated
   - Archive Streamlit installation
   - Train team on new system
   - Go live with Solar Calculator Pro
