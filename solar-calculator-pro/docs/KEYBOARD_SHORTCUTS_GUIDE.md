# Keyboard Shortcuts Guide

## Overview

The Solar Calculator Pro application provides comprehensive keyboard shortcut support for efficient navigation and operation. Shortcuts are organized into global shortcuts (available everywhere) and context-specific shortcuts (available on specific pages).

## Features

- **Global Shortcuts**: Work anywhere in the application
- **Context-Specific Shortcuts**: Activate based on current page
- **Customization**: Modify shortcuts to match your workflow
- **Conflict Detection**: Automatically detect and warn about conflicting shortcuts
- **Cheat Sheet**: Quick reference for all available shortcuts
- **Help Dialog**: Press `Ctrl+Shift+?` to view shortcuts anytime

## Customizing Shortcuts

### Via Settings UI

1. Navigate to **Settings** → **Keyboard Shortcuts**
2. Find the shortcut you want to modify
3. Click the **Edit** button
4. Enter the new shortcut combination
5. Click **Save**

### Conflict Detection

The system automatically detects conflicts when:
- Two shortcuts use the same key combination
- Shortcuts are in the same context

Conflicts are displayed in the **Conflicts** tab with suggestions for resolution.

### Resetting Shortcuts

To reset shortcuts to defaults:
1. Go to **Settings** → **Keyboard Shortcuts**
2. Click **Reset All** to reset all shortcuts
3. Or click **Reset** next to individual shortcuts

## Shortcut Format

Shortcuts follow this format: `Modifier+Key`

### Modifiers

- `Ctrl` - Control key (Command on macOS)
- `Alt` - Alt key (Option on macOS)
- `Shift` - Shift key
- `Cmd` - Command key (macOS only)

### Examples

- `Ctrl+S` - Control + S
- `Ctrl+Shift+P` - Control + Shift + P
- `Alt+F4` - Alt + F4

## Best Practices

1. **Learn Gradually**: Start with the most common shortcuts
2. **Use Cheat Sheet**: Keep the cheat sheet handy (`Ctrl+Shift+?`)
3. **Customize Wisely**: Only customize shortcuts that conflict with your workflow
4. **Avoid Conflicts**: Check for conflicts before saving custom shortcuts
5. **Context Awareness**: Remember that some shortcuts only work on specific pages

## Accessibility

- All shortcuts are keyboard-accessible
- Screen readers announce shortcut actions
- Shortcuts can be disabled in accessibility settings
- Alternative navigation methods are always available

## Troubleshooting

### Shortcut Not Working

1. Check if shortcuts are enabled (Settings → Keyboard Shortcuts)
2. Verify you're in the correct context for context-specific shortcuts
3. Check for conflicts in the Conflicts tab
4. Ensure the application window has focus

### Conflict Resolution

1. Go to Settings → Keyboard Shortcuts → Conflicts tab
2. Review conflicting shortcuts
3. Modify one of the conflicting shortcuts
4. Save changes

### Resetting to Defaults

If shortcuts become misconfigured:
1. Go to Settings → Keyboard Shortcuts
2. Click **Reset All**
3. Confirm the action

## Platform-Specific Notes

### Windows

- `Ctrl` is the primary modifier
- `Alt+F4` closes the application
- `F11` toggles fullscreen

### macOS

- `Cmd` (⌘) replaces `Ctrl` in most shortcuts
- `Cmd+Q` quits the application
- `Cmd+W` closes the window

### Linux

- Similar to Windows
- Window manager shortcuts may take precedence
- Some shortcuts may need customization
