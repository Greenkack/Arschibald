## Creating Projects

### Step 1: Customer Information

1. Click "New Project"
2. Enter customer details:
   - Name
   - Address
   - Contact information
   - Email

### Step 2: Building Data

1. Select building type
2. Enter roof dimensions
3. Specify roof orientation
4. Add any obstacles or shading

### Step 3: Energy Analysis

1. Enter current energy consumption
2. Specify electricity tariff
3. Add any special requirements

### Step 4: System Configuration

1. Select PV modules
2. Choose inverter
3. Add battery storage (optional)
4. Configure mounting system

### Step 5: Review and Save

1. Review all entered data
2. Generate initial calculation
3. Save project

## Troubleshooting

### Common Issues

#### Login Problems
- Check username/password
- Clear browser cache
- Contact administrator

#### Calculation Errors
- Verify input data
- Check for missing fields
- Review error messages

#### PDF Generation Issues
- Check browser popup blocker
- Verify data completeness
- Try different browser
